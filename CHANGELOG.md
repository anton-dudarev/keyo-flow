# История изменений Keyo

## Unreleased

- Добавлен движок воспроизведения сценариев с настройкой скорости и числа повторов, прерываемым ожиданием и освобождением модификаторов.
- Добавлена команда `keyo play` для Windows с предварительной проверкой JSON через `--dry-run` и аварийной остановкой по `Esc`.
- Движок освобождает все зажатые сценарием клавиши и кнопки мыши при завершении, отмене или ошибке.
- Добавлена команда `keyo record` для Windows. Она записывает мышь и поддерживаемые клавиши в новый файл JSON, исключает синтетический ввод и завершает запись по `Esc`.

## 0.1.0 — 2026-11-16

- Добавлена модель сценария, которая хранит события мыши и клавиатуры в порядке воспроизведения с относительными задержками.
- Добавлены чтение и запись сценариев в JSON версии 1. При загрузке неизвестной версии возвращается ошибка.
