# Keyo

Keyo — проект утилиты для тестирования пользовательских интерфейсов через эмуляцию действий мыши и клавиатуры. Идея в том, чтобы записать последовательность действий один раз и повторять её при проверке интерфейса, например после изменений в форме или диалоге.

## Текущее состояние

Keyo доступен как библиотека Rust и как утилита для записи и воспроизведения сценариев на Windows с консольным и графическим интерфейсами. Уже реализованы:

- Модель сценария с событиями мыши и клавиатуры и относительными задержками.
- Чтение и запись сценариев в JSON версии 2.
- Запись действий мыши и поддерживаемых клавиш с прореживанием движений курсора.
- Движок воспроизведения в отдельном потоке с настройкой скорости и числа повторов через API библиотеки, прерываемым ожиданием и освобождением зажатых клавиш и кнопок мыши.

Поддержку macOS и Linux рассмотрим после первого релиза Windows.

## Графический интерфейс Windows

```sh
cargo run --locked --features gui --bin keyo-gui
```

Нажми «Открыть JSON» и выбери сценарий, например `scenario.json` из корня репозитория. Keyo покажет число событий и длительность. Нажми «Воспроизвести» и переключись в тестовое окно за три секунды. Отсчёт и воспроизведение можно отменить кнопкой «Стоп» или клавишей `Esc`. Окно следует светлой или тёмной системной теме Windows.

Внизу окна отображаются до десяти недавно открытых или сохранённых сценариев. Дважды щёлкни по имени, чтобы открыть файл. При следующем запуске Keyo восстанавливает положение главного окна и список недавних. Сценарий выбирается вручную.

Кнопка с шестерёнкой открывает настройки горячих клавиш записи и воспроизведения. Укажи основную клавишу и модификаторы `Ctrl`, `Alt`, `Shift` или `Win`. Сочетания работают, когда окно Keyo в фоне. Если Windows не принимает сочетание, выбери другое. Кнопка «Очистить» убирает привязку после сохранения.

Перед запуском можно выбрать скорость от `0,25×` до `4×` и количество запусков. По умолчанию сценарий выполнится один раз на скорости `1×`. Режим «Повторять бесконечно» запускает сценарий по кругу до остановки. Во время воспроизведения окно показывает номер текущего запуска.

После загрузки JSON нажми «Редактировать». Список действий откроется в отдельном окне, которое запоминает положение, размер и состояние разворачивания. Перетаскивай строки за нужное место в списке. Задержка перемещается вместе с действием. Кнопка «Добавить позицию» вставляет новое действие сразу под выбранной строкой после ввода параметров и задержки.

Дважды щёлкни по строке или выбери её и нажми «Изменить». Форма откроется с текущими значениями. Можно изменить действие, его параметры и задержку. «Применить» обновляет строку в черновике. Чтобы выйти из формы без применения правки строки, нажми `Esc` или щёлкни по пустой области редактора.

Для действия с клавиатурой введи имя или нажми «Выбрать клавишу» и воспользуйся поиском. В списке есть пробел, стрелки, `Backspace`, `F1`–`F24`, цифровой блок, пунктуация и мультимедийные клавиши.

При удалении строки её задержка переносится к следующему событию. Нажми «Готово», чтобы воспроизвести отредактированный сценарий или записать правки в текущий JSON кнопкой «Сохранить изменения». Keyo запросит подтверждение перезаписи. В диалоге закрытия кнопка «Сохранить и закрыть» также сохраняет правки в текущий файл. Для новой записи Keyo предложит выбрать путь.

В списке событий `Ctrl+A` выделяет все строки, `Shift+щелчок` выделяет диапазон, а `Ctrl+щелчок` переключает выделение отдельной строки. `Del` удаляет выделенные строки с сохранением времени оставшихся действий. При вводе в текстовом поле сочетания работают с текстом.

Чтобы записать сценарий, нажми «Записать» или назначенное сочетание, переключись в тестовое окно за три секунды и выполни нужные действия. Чтобы завершить запись, повтори сочетание или нажми «Стоп». После завершения выбери имя файла в диалоге сохранения. Если закрыть диалог, запись останется в окне до сохранения или явного удаления.

## Запись на Windows

Запусти команду с новым именем файла:

```sh
cargo run --locked --bin keyo -- record recorded.json
```

Переключись в тестовое окно за три секунды, дождись начала записи и выполни проверяемые действия. Чтобы завершить запись и сохранить сценарий, вернись в консоль и нажми `Ctrl+C`. Существующий файл защищён от перезаписи.

Во время записи Keyo получает ввод из активных окон. Используй тестовые данные. `Esc` записывается как обычное действие. Синтетический ввод и служебное сочетание остановки пропускаются.

## Воспроизведение на Windows

Проверь готовый JSON-сценарий перед запуском:

```sh
cargo run --locked --bin keyo -- play scenario.json --dry-run
```

Для реального прогона убери `--dry-run`. Через три секунды Keyo один раз воспроизведёт сценарий с исходной скоростью в текущем активном окне. За это время переключись в тестовое окно. Нажми `Esc`, чтобы отменить запуск или остановить воспроизведение.

Координаты сценария задаются в физических пикселях виртуального рабочего стола. Отрицательные координаты поддерживаются. В поле `key` используй строки `"A"`–`"Z"`, `"0"`–`"9"` или имя специальной клавиши, например `"Enter"`, `"ShiftLeft"` или `"F5"`. Редактор принимает имена без учёта регистра и записывает их в форме из списка. Результат нажатия клавиш пунктуации зависит от активной раскладки.

Неподдерживаемое событие или координата за границами рабочего стола вызовут ошибку до начала воспроизведения. Keyo этого выпуска открывает сценарии с `"version": 2`.

## Сборка и проверка

Для работы нужен Rust с Cargo. Выполни в корне репозитория:

```sh
cargo build --locked
cargo test --locked --lib
```

Сборка создаёт библиотеку и исполняемый файл `keyo`. Модульные тесты проверяют движок через подставной адаптер и не управляют мышью или клавиатурой.
