# Keyo

Keyo — проект утилиты для тестирования пользовательских интерфейсов через эмуляцию действий мыши и клавиатуры. Идея в том, чтобы записать последовательность действий один раз и повторять её при проверке интерфейса, например после изменений в форме или диалоге.

## Текущее состояние

Сейчас Keyo доступен как библиотека Rust. В ней реализованы:

- Модель сценария с событиями мыши и клавиатуры и относительными задержками.
- Чтение и запись сценариев в JSON версии 1.
- Движок воспроизведения в отдельном потоке с настройкой скорости и числа повторов, прерываемым ожиданием и освобождением модификаторов.

Движок передаёт события адаптеру ввода. Адаптеры ОС для записи и эмуляции, глобальная клавиша аварийной остановки и графический интерфейс запланированы.

## Сборка и проверка

Для работы нужен Rust с Cargo. Выполни в корне репозитория:

```sh
cargo build --locked
cargo test --locked --lib
```

Сборка создаёт библиотеку. Модульные тесты используют подставной адаптер и не управляют мышью или клавиатурой.
