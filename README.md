# Keyo

Keyo — проект утилиты для тестирования пользовательских интерфейсов через эмуляцию действий мыши и клавиатуры. Идея в том, чтобы записать последовательность действий один раз и повторять её при проверке интерфейса, например после изменений в форме или диалоге.

## Текущее состояние

Keyo доступен как библиотека Rust и как утилита для записи и воспроизведения сценариев на Windows с консольным и графическим интерфейсами. Уже реализованы:

- Модель сценария с событиями мыши и клавиатуры и относительными задержками.
- Чтение и запись сценариев в JSON версий 2 и 3: координаты рабочего стола и координаты тестового окна.
- Запись действий мыши и поддерживаемых клавиш с прореживанием движений курсора.
- Движок воспроизведения в отдельном потоке с настройкой скорости и числа повторов через API библиотеки, прерываемым ожиданием и освобождением зажатых клавиш и кнопок мыши.

Поддержку macOS и Linux рассмотрим после первого релиза Windows.

## Графический интерфейс Windows

```sh
cargo run --locked --features gui --bin keyo-gui
```

Нажми «Открыть JSON» и выбери сценарий, например `scenario.json` из корня репозитория. При первом открытии диалог показывает папку `keyo-gui.exe`. После успешного открытия Keyo запоминает папку сценария и предлагает её при следующем запуске. Если папка больше недоступна, диалог снова открывается рядом с EXE. Keyo покажет число событий и длительность. Нажми «Воспроизвести» и переключись в тестовое окно за три секунды. Отсчёт и воспроизведение можно отменить кнопкой «Стоп» или клавишей `Esc`. Окно следует светлой или тёмной системной теме Windows.

В GUI и CLI можно также остановить воспроизведение мышью. Уведи курсор в верхний левый угол **основного монитора** и задержи его там на четверть секунды. Зона остановки занимает 8×8 физических пикселей. Движение мыши, которое выполняет сам сценарий, эту остановку не запускает.

Внизу окна отображаются до десяти недавно открытых или сохранённых сценариев. Дважды щёлкни по имени, чтобы открыть файл. При следующем запуске Keyo восстанавливает положение главного окна и список недавних. Сценарий выбирается вручную.

Кнопка с шестерёнкой открывает настройки горячих клавиш записи и воспроизведения. По умолчанию запись запускается через `Alt+Shift+Win+R`, а воспроизведение — через `Alt+Shift+Win+P`. Можно назначить другую клавишу и модификаторы `Ctrl`, `Alt`, `Shift` или `Win`. Сочетания работают, когда окно Keyo в фоне. Если Windows не принимает сочетание, выбери другое. Кнопка «Очистить» убирает привязку после сохранения.

Перед запуском можно выбрать скорость от `0,25×` до `4×` и количество запусков. По умолчанию сценарий выполнится один раз на скорости `1×`. Во время воспроизведения окно показывает номер текущего запуска и примерное время до завершения всех повторов. В режиме «Повторять бесконечно» видны номер и прогресс текущего запуска. Если выбранное тестовое окно должно оставаться активным, за прогрессом можно следить, расположив Keyo рядом или на другом мониторе. Переключение на Keyo остановит сценарий.

В списке «Тестовое окно» можно выбрать открытое окно и переключиться в него во время отсчёта. Если к концу отсчёта окно не активно или теряет фокус во время воспроизведения, Keyo останавливает сценарий. По умолчанию выбрано «Любое активное окно».

Чтобы следить за прогрессом поверх тестового окна, включи в настройках «Показывать индикатор воспроизведения». Индикатор появляется на мониторе активного окна во время воспроизведения и пропускает щелчки. Счётчик `122/1000` означает, что завершены 122 повтора из 1000. В бесконечном режиме он показывает `122/∞`. По умолчанию настройка выключена.

В списке отображаются видимые окна верхнего уровня, для которых Windows возвращает непустой заголовок. Если нужного окна нет в списке, нажми «Выбрать переключением» и переключись в него за три секунды. Keyo запомнит окно, активное в конце отсчёта. Чтобы отменить выбор, нажми `Esc`. Этот способ подходит и для сценариев с координатами окна.

Если Windows отклоняет ввод, Keyo предлагает проверить, запущено ли тестовое окно от имени администратора. Подсказка отображается в GUI и CLI.

Чтобы перенести сценарий на окно другого размера или положения, выбери тестовое окно, включи «Записывать координаты относительно окна» и начни запись. Keyo сохраняет доли ширины и высоты клиентской области без заголовка и рамок. Если окно потеряет фокус, переместится или изменит размер во время записи, запись завершится. Щелчок или прокрутка за пределами клиентской области также завершает запись.

Такой сценарий сохраняется как JSON версии 3. Координаты в нём целые, от `0` до `1000000`, где `500000` соответствует середине. При воспроизведении выбери тестовое окно. Keyo вычислит позиции по его текущей клиентской области. Изменение компоновки элементов интерфейса может потребовать новой записи.

После загрузки JSON нажми «Редактировать». Список действий откроется в отдельном окне, которое запоминает положение, размер и состояние разворачивания. Перетаскивай строки за нужное место в списке. Задержка перемещается вместе с действием. Кнопка «Добавить позицию» вставляет новое действие сразу под выбранной строкой после ввода параметров и задержки.

Дважды щёлкни по строке или выбери её и нажми «Изменить». Форма откроется с текущими значениями. Можно изменить действие, его параметры и задержку. «Применить» обновляет строку в черновике. Чтобы выйти из формы без применения правки строки, нажми `Esc` или щёлкни по пустой области редактора.

Для действия с клавиатурой введи имя или нажми «Выбрать клавишу» и воспользуйся поиском. В списке есть пробел, стрелки, `Backspace`, `F1`–`F24`, цифровой блок, пунктуация и мультимедийные клавиши.

При удалении строки её задержка переносится к следующему событию. Нажми «Готово», чтобы воспроизвести отредактированный сценарий или записать правки в текущий JSON кнопкой «Сохранить изменения». Keyo запросит подтверждение перезаписи. В диалоге закрытия кнопка «Сохранить и закрыть» также сохраняет правки в текущий файл. Для новой записи Keyo предложит выбрать путь.

В списке событий `Ctrl+A` выделяет все строки, `Shift+щелчок` выделяет диапазон, а `Ctrl+щелчок` переключает выделение отдельной строки. `Del` удаляет выделенные строки с сохранением времени оставшихся действий. При вводе в текстовом поле сочетания работают с текстом.

Чтобы записать сценарий, нажми «Записать» или назначенное сочетание, переключись в тестовое окно за три секунды и выполни нужные действия. Чтобы завершить запись, повтори сочетание или нажми «Стоп». После завершения выбери имя файла в диалоге сохранения. Если закрыть диалог, запись останется в окне до сохранения или явного удаления.

## Запись на Windows

Запусти команду с новым именем файла:

```sh
cargo run --locked --bin keyo-cli -- record recorded.json
```

Переключись в тестовое окно за три секунды, дождись начала записи и выполни проверяемые действия. Чтобы завершить запись и сохранить сценарий, вернись в консоль и нажми `Ctrl+C`. Существующий файл защищён от перезаписи.

Во время записи Keyo получает ввод из активных окон. Используй тестовые данные. `Esc` записывается как обычное действие. Синтетический ввод и служебное сочетание остановки пропускаются.

## Воспроизведение на Windows

Проверь готовый JSON-сценарий перед запуском:

```sh
cargo run --locked --bin keyo-cli -- play scenario.json --dry-run
```

Для реального прогона убери `--dry-run`. Через три секунды Keyo один раз воспроизведёт сценарий с исходной скоростью в текущем активном окне. За это время переключись в тестовое окно. Нажми `Esc`, чтобы отменить запуск или остановить воспроизведение.

Координаты сценария версии 2 задаются в физических пикселях виртуального рабочего стола. Отрицательные координаты поддерживаются. В поле `key` используй строки `"A"`–`"Z"`, `"0"`–`"9"` или имя специальной клавиши, например `"Enter"`, `"ShiftLeft"` или `"F5"`. Редактор принимает имена без учёта регистра и записывает их в форме из списка. Результат нажатия клавиш пунктуации зависит от активной раскладки.

Неподдерживаемое событие или координата за границами рабочего стола вызовут ошибку до начала воспроизведения. CLI проверяет JSON версий 2 и 3 с `--dry-run`. Воспроизведение версии 3 требует выбора тестового окна в GUI.

## Сборка и проверка

Для работы нужен Rust с Cargo. Выполни в корне репозитория:

```sh
cargo build --locked --features gui --bins
cargo test --locked --features gui --lib
```

Сборка создаёт `keyo-cli.exe` и `keyo-gui.exe`. Модульные тесты проверяют движок и интерфейс без управления мышью или клавиатурой.
