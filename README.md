# Keyo

Keyo — проект утилиты для тестирования пользовательских интерфейсов через эмуляцию действий мыши и клавиатуры. Идея в том, чтобы записать последовательность действий один раз и повторять её при проверке интерфейса, например после изменений в форме или диалоге.

## Текущее состояние

Keyo доступен как библиотека Rust и как утилита для записи и воспроизведения сценариев на Windows с консольным и графическим интерфейсами. Уже реализованы:

- Модель сценария с событиями мыши и клавиатуры и относительными задержками.
- Чтение и запись сценариев в JSON версий 2 и 3: координаты рабочего стола и координаты целевого окна.
- Запись действий мыши и поддерживаемых клавиш с прореживанием движений курсора.
- Движок воспроизведения в отдельном потоке с настройкой скорости и числа повторов через API библиотеки, прерываемым ожиданием и освобождением зажатых клавиш и кнопок мыши.

Готовая сборка доступна для Windows x64. Распакуй ZIP и запусти `keyo-gui.exe`. В архиве также есть `keyo-cli.exe` и демонстрационный сценарий `scenario.json`. [Скачать последний релиз](https://github.com/anton-dudarev/keyo-flow/releases/latest)

## Графический интерфейс Windows

Графический интерфейс использует DirectX 12 через wgpu и не требует OpenGL. Если подходящий аппаратный адаптер недоступен, может использоваться встроенный в Windows программный адаптер WARP. Программный рендеринг увеличивает нагрузку на процессор. Запуск на конкретной виртуальной машине зависит от доступности совместимого DirectX 12 устройства.

```sh
cargo run --locked --features gui --bin keyo-gui
```

Нажми «Открыть JSON» и выбери сценарий. При первом открытии диалог показывает папку `keyo-gui.exe`. После успешного открытия Keyo запоминает папку сценария и предлагает её при следующем запуске. Если папка больше недоступна, диалог снова открывается рядом с EXE. Keyo покажет число событий и длительность. Нажми «Воспроизвести» и переключись в целевое окно за три секунды. Отсчёт и воспроизведение можно отменить кнопкой «Стоп» или клавишей `Esc`. Окно следует светлой или тёмной системной теме Windows.

Загрузи [демонстрационный сценарий](scenario.json) в Keyo, открой пустой документ в Блокноте и выбери окно Блокнота в списке «Целевое окно». Нажми «Воспроизвести» и переключись в Блокнот за три секунды. Пример использует JSON версии 3. Курсор переместится в пределах окна, пройдёт плавный отрезок и замкнутую траекторию, затем щёлкнет в области текста. В конце Keyo нажмёт клавишу `F` по скан-коду. При выключенном Caps Lock появится `f` в английской раскладке или `а` в русской.

В GUI и CLI можно также остановить воспроизведение мышью. Уведи курсор в верхний левый угол **основного монитора** и задержи его там на четверть секунды. Зона остановки занимает 8×8 физических пикселей. Движение мыши, которое выполняет сам сценарий, эту остановку не запускает.

Внизу окна отображаются до десяти недавно открытых или сохранённых сценариев. Дважды щёлкни по имени, чтобы открыть файл. При следующем запуске Keyo восстанавливает положение главного окна и список недавних. Сценарий выбирается вручную.

Кнопка с шестерёнкой открывает настройки горячих клавиш записи и воспроизведения. По умолчанию запись запускается через `Alt+Shift+Win+R`, а воспроизведение — через `Alt+Shift+Win+P`. Можно назначить другую клавишу и модификаторы `Ctrl`, `Alt`, `Shift` или `Win`. Сочетания работают, когда окно Keyo в фоне. Если Windows не принимает сочетание, выбери другое. Кнопка «Очистить» убирает привязку после сохранения.

В настройках есть «Разброс времени воспроизведения». Для задержек и удержаний задаются отдельные проценты от 0 до 100. При 10% пауза 100 мс изменяется в пределах 90–110 мс. Значения выбираются по ограниченному нормальному распределению: небольшие отклонения встречаются чаще предельных. По умолчанию оба процента равны нулю. Параметры сохраняются между запусками, а исходный сценарий хранит записанное время.

Разброс задержек применяется к паузам, во время которых клавиши и кнопки мыши отпущены. Разброс удержаний меняет время отпускания клавиш и кнопок. Для сохранения порядка действий диапазон удержания ограничивается соседними событиями. Это особенно важно для сочетаний и перетаскивания. При включённом разбросе оставшееся время в индикаторе оценивается по исходной длительности сценария.

«Начальное значение» задаёт последовательность случайных изменений. Одинаковый сценарий, скорость, проценты и начальное значение дают тот же разброс. Каждый повтор получает следующие значения этой последовательности. Чтобы получить другую последовательность, измени начальное значение. Эти настройки применяются к воспроизведению из GUI.

Перед запуском можно выбрать скорость от `0,25×` до `4×` и количество запусков. По умолчанию сценарий выполнится один раз на скорости `1×`. Во время воспроизведения окно показывает номер текущего запуска и примерное время до завершения всех повторов. В режиме «Повторять бесконечно» видны номер и прогресс текущего запуска. Если выбранное целевое окно должно оставаться активным, за прогрессом можно следить, расположив Keyo рядом или на другом мониторе. Переключение на Keyo остановит сценарий.

В списке «Целевое окно» можно выбрать открытое окно и переключиться в него во время отсчёта. Если к концу отсчёта окно не активно или теряет фокус во время воспроизведения, Keyo останавливает сценарий. По умолчанию выбрано «Любое активное окно».

Индикатор воспроизведения включён по умолчанию. Он появляется на мониторе активного окна во время воспроизведения и пропускает щелчки. Счётчик `122/1000` означает, что завершены 122 повтора из 1000. В бесконечном режиме он показывает `122/∞`. Чтобы скрыть индикатор, сними галочку «Показывать индикатор воспроизведения» в настройках.

В списке отображаются видимые окна верхнего уровня, для которых Windows возвращает непустой заголовок. Если нужного окна нет в списке, нажми «Выбрать переключением» и переключись в него за три секунды. Keyo запомнит окно, активное в конце отсчёта. Чтобы отменить выбор, нажми `Esc`. Этот способ подходит и для сценариев с координатами окна.

Если Windows отклоняет ввод, Keyo предлагает проверить, запущено ли целевое окно от имени администратора. Подсказка отображается в GUI и CLI.

Чтобы перенести сценарий на окно другого размера или положения, выбери целевое окно, включи «Записывать координаты относительно окна» и начни запись. Keyo сохраняет доли ширины и высоты клиентской области без заголовка и рамок. Если окно потеряет фокус, переместится или изменит размер во время записи, запись завершится. Щелчок или прокрутка за пределами клиентской области также завершает запись.

Такой сценарий сохраняется как JSON версии 3. Координаты в нём целые, от `0` до `1000000`, где `500000` соответствует середине. При воспроизведении выбери целевое окно. Keyo вычислит позиции по его текущей клиентской области. Изменение компоновки элементов интерфейса может потребовать новой записи.

После загрузки JSON нажми «Редактировать». Список действий откроется в отдельном окне, которое запоминает положение, размер и состояние разворачивания. Перетаскивай строки за нужное место в списке. Задержка перемещается вместе с действием. Кнопка «Добавить позицию» вставляет новое действие сразу под выбранной строкой после ввода параметров и задержки.

Дважды щёлкни по строке или выбери её и нажми «Изменить». Форма откроется с текущими значениями. Можно изменить действие, его параметры и задержку. «Применить» обновляет строку в черновике. Чтобы выйти из формы без применения правки строки, нажми `Esc` или щёлкни по пустой области редактора.

Чтобы добавить плавное перемещение, выбери исходную позицию курсора или строку после неё, нажми «Добавить позицию» и включи «Плавное перемещение» для действия перемещения. Укажи конечные координаты и длительность в миллисекундах. Keyo сохранит движение одной строкой и рассчитает промежуточные точки при воспроизведении. Начальная точка берётся из ближайшего предыдущего перемещения. Задержка перед движением задаётся отдельно.

Для действия с клавиатурой введи имя или нажми «Выбрать клавишу» и воспользуйся поиском. В списке есть пробел, стрелки, `Backspace`, `F1`–`F24`, цифровой блок, пунктуация и мультимедийные клавиши.

При записи каждое полностью записанное нажатие сохраняется одной строкой «Удержание клавиши» с фактической длительностью. Перекрытия сохраняются: например, Keyo может удерживать Ctrl, пока выполняется нажатие C. Задержка следующей строки после записанного удержания отсчитывается от начала удержания. Если запись закончилась до отпускания клавиши, остаётся отдельное нажатие. Автоповтор клавиши сохраняется отдельными событиями нажатия.

Для кнопок мыши запись создаёт «Удержание кнопки мыши» с фактической длительностью. Движения во время удержания сохраняют перетаскивание. Такую строку можно редактировать и разделить на нажатие и отпускание той же командой, что и для клавиши.

Для обратной операции выдели строку нажатия и следующую за ней строку отпускания, затем нажми «Объединить в удержание». Между выбранными строками могут находиться другие действия. Клавиша или кнопка берётся из строки нажатия: нажатие D и отпускание F создадут удержание D. Длительность рассчитывается по исходным моментам событий, остальные действия сохраняют своё время. Объединять можно события одного устройства — две строки клавиатуры либо две строки мыши.

Чтобы отредактировать нажатие и отпускание по отдельности, выдели удержание и нажми «Разделить на нажатие и отпускание». Keyo разместит отпускание на исходном месте временной шкалы среди остальных действий. Удержание также можно добавить вручную с заданной длительностью в миллисекундах. После вручную добавленного удержания клавиши задержка следующего действия отсчитывается от отпускания. Для удержания кнопки мыши она отсчитывается от нажатия, поэтому следующие действия могут выполняться во время удержания.

Последовательные движения мыши с паузами до 100 мс сворачиваются в строку «Траектория курсора». Все записанные точки и их время сохраняются. Нажми «Раскрыть траекторию» или дважды щёлкни по строке, чтобы показать подстроки с координатами и задержками между точками. Значения редактируются прямо в подстроках. Щелчок по имени точки выделяет её, `Ctrl+щелчок` переключает выделение, `Shift+щелчок` выбирает диапазон. `Ctrl+A` при выбранной точке выделяет все точки этой траектории. `Del` или «Удалить точки» удаляет выделенные точки с сохранением времени оставшихся действий. Если удалены все точки, траектория удаляется целиком. «Свернуть траекторию» скрывает подробности. Раскрытие и сворачивание меняют отображение редактора, а траектория сохраняется одним действием. Если отпускание разделяемой клавиши попадает внутрь траектории, при разделении удержания Keyo преобразует её в отдельные события для размещения отпускания между точками.

При удалении строки её задержка переносится к следующему событию. Нажми «Готово», чтобы воспроизвести отредактированный сценарий или записать правки в текущий JSON кнопкой «Сохранить изменения». Keyo запросит подтверждение перезаписи. В диалоге закрытия кнопка «Сохранить и закрыть» также сохраняет правки в текущий файл. Для новой записи Keyo предложит выбрать путь.

В списке событий `Ctrl+A` выделяет все строки, `Shift+щелчок` выделяет диапазон, а `Ctrl+щелчок` переключает выделение отдельной строки. `Del` удаляет выделенные строки с сохранением времени оставшихся действий. При вводе в текстовом поле сочетания работают с текстом.

Чтобы записать сценарий, нажми «Записать» или назначенное сочетание, переключись в целевое окно за три секунды и выполни нужные действия. Чтобы завершить запись прямо в целевом окне, повтори сочетание записи. Keyo исключает служебное сочетание из сценария. Запись также можно завершить кнопкой «Стоп». Если при переходе к Keyo в сценарий попали лишние действия, удали их в редакторе. Если закрыть диалог сохранения, используй «Сохранить JSON», чтобы вернуться к выбору файла, или «Отменить запись», чтобы удалить несохранённый сценарий.

## Запись на Windows

Запусти команду с новым именем файла:

```sh
cargo run --locked --bin keyo-cli -- record recorded.json
```

Переключись в целевое окно за три секунды, дождись начала записи и выполни проверяемые действия. Чтобы завершить запись и сохранить сценарий, вернись в консоль и нажми `Ctrl+C`. Существующий файл защищён от перезаписи.

Во время записи Keyo получает ввод из активных окон. Используй тестовые данные. `Esc` записывается как обычное действие. Синтетический ввод пропускается. В CLI `Ctrl+C` завершает запись через обработчик консоли. Проверь конец сценария, если для остановки переключался в консоль.

## Воспроизведение на Windows

Проверь готовый JSON-сценарий перед запуском:

```sh
cargo run --locked --bin keyo-cli -- play scenario.json --dry-run
```

Демонстрационный `scenario.json` воспроизводится из GUI после выбора целевого окна. Для реального прогона сценария версии 2 через CLI подставь путь к этому сценарию и убери `--dry-run`. Через три секунды Keyo один раз воспроизведёт сценарий с исходной скоростью в текущем активном окне. За это время переключись в целевое окно. Нажми `Esc`, чтобы отменить запуск или остановить воспроизведение.

Координаты сценария версии 2 задаются в физических пикселях виртуального рабочего стола. Отрицательные координаты поддерживаются. В поле `key` используй строки `"A"`–`"Z"`, `"0"`–`"9"` или имя специальной клавиши, например `"Enter"`, `"ShiftLeft"` или `"F5"`. Редактор принимает имена без учёта регистра и записывает их в форме из списка.

При записи клавиатуры Keyo сохраняет скан-код физической клавиши, если Windows передаёт его в поддерживаемом виде. При воспроизведении Windows применяет активную раскладку получателя ввода. Например, физическая клавиша `F` в обычном текстовом поле даёт `f` при английской раскладке и `а` при русской. Имя в поле `key` остаётся идентификатором для редактора. Сценарии версий 2 и 3 без поля `scan_code` по-прежнему воспроизводят клавиши по имени.

Неподдерживаемое событие или координата за границами рабочего стола вызовут ошибку до начала воспроизведения. CLI проверяет JSON версий 2 и 3 с `--dry-run`. Воспроизведение версии 3 требует выбора целевого окна в GUI.

## Сборка и проверка

Для сборки GUI нужен Rust 1.95 или новее с Cargo. Выполни в корне репозитория:

```sh
cargo build --locked --features gui --bins
cargo test --locked --features gui --lib
```

Сборка создаёт `keyo-cli.exe` и `keyo-gui.exe`. Модульные тесты проверяют движок и интерфейс без управления мышью или клавиатурой.

Правила участия описаны в [CONTRIBUTING.md](CONTRIBUTING.md), история версий — в [CHANGELOG.md](CHANGELOG.md).
